# Clonar rama, modificar y subir cambios.

## 📝 Práctica: Uso de Git y GitHub con ramas

Práctica destinada a aprender el flujo básico de trabajo con **Git** y **GitHub**, incluyendo la creación de ramas y la gestión de cambios a través de **powershell** o **CMD** en un proyecto sencillo en **Java**.

---

## 🚀 Objetivos de la práctica

- Crear un repositorio en GitHub.
- Añadir un archivo Java inicial.
- Crear una rama de desarrollo para trabajar de forma aislada.
- Modificar el código desde **POWERSHELL** O **CMD**
- Subir los cambios al repositorio.
- Integrar los cambios en la rama principal.

---

---

## 🔧 Pasos realizados

1. Creación del repositorio en GitHub.
2. Subida del código Java inicial.
3. Creación de una nueva rama.
4. Modificación del código usando comandos en **powershell**
5. Realización de commits y push de los cambios.
6. Actualización del repositorio con las modificaciones.

---

## 📌 Tecnologías utilizadas

- Java  
- Git  
- GitHub  

---

## 📖 Descripción breve

El objetivo principal es trabajar desde **powershell** con ramas y realizar desde aquí todos los cambios necesarios en el repositorio, permitiendo desarrollar nuevas funcionalidades sin afectar directamente a la rama principal del proyecto.
